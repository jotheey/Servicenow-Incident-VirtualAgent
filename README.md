# Contextual AI Incident Communication Assistant

A ServiceNow proof of concept that helps Incident Analysts communicate with stakeholders through Microsoft Teams using contextual AI.

## Project Status

🚧 Day 1 - Foundation

## Objective

Allow an Incident Analyst to use a contextual Virtual Agent from an Incident record to:

1. Identify the caller or assigned engineer.
2. Understand the analyst's follow-up request.
3. Generate a professional Teams message.
4. Preview the message.
5. Obtain analyst confirmation.
6. Send the message through Microsoft Teams.
7. Record the communication against the Incident.
